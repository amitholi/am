# עוזר AI בעברית ב-iPhone

חבילת הגדרה ל-iPhone 17 Pro, iOS 26.x, ממשק iOS באנגלית.
המטרה: לעבוד מול ChatGPT בעברית מהטלפון, סביב העובדה ש-Siri לא מדבר עברית ולא יידע לדבר עברית.

---

## מה עובד

| יכולת | דרך | הערה |
|---|---|---|
| הקלדה בדיבור בעברית | iOS keyboard dictation | המסלול האמין היחיד ל-speech-to-text בעברית במכשיר |
| שיחה קולית מלאה בעברית | ChatGPT app ← Voice Mode | דו-כיווני: מבין עברית, עונה בעברית בקול |
| תשובות טקסט בעברית תמיד | ChatGPT Custom Instructions | גם כשהקלט מגיע באנגלית שבורה מתמלול |
| שאלה ל-ChatGPT דרך Siri | Siri ← ChatGPT extension | אתה מדבר אנגלית, התשובה חוזרת בעברית **בטקסט על הכרטיס** |
| עריכת טקסט עברי בלחיצה | Shortcut + Back Tap / Action Button | העתק ← הפעל ← בחר סגנון ← הדבק |

## מה לא עובד, ולמה

| מה | למה | מה עושים במקום |
|---|---|---|
| Siri בעברית | אין עברית כשפת קלט של Siri. אין הגדרה, אין עקיפה, אין פרופיל אזורי שפותח את זה | ChatGPT Voice Mode |
| Siri מקריא עברית | אין TTS בעברית ב-Siri | ChatGPT Voice Mode |
| Apple Intelligence בעברית | אין תמיכה בעברית | ChatGPT, ישירות |
| Apple Writing Tools ב-WhatsApp | Meta חוסמת אותם באפליקציה. גם ללא החסימה — אין עברית ב-Apple Intelligence | קיצור "ערוך הודעה" דרך הלוח |
| דיבור עברית ל-Siri שיגיע ל-ChatGPT | ההרחבה מעבירה טקסט מתומלל באנגלית בלבד | ChatGPT Voice Mode, או הכתבת מקלדת ואז הדבקה |
| החלפת טקסט במקום באפליקציית המקור | תפריט השיתוף לא יכול לכתוב בחזרה לאפליקציה | הפלט חוזר ללוח, מדביקים ידנית |

**התובנה המרכזית:** Siri הוא לא הדלת לעברית. הוא לכל היותר צינור אנגלי ל-ChatGPT, שממנו התשובה חוזרת בעברית בכתב. כל מה שקולי ובעברית עובר דרך אפליקציית ChatGPT.

## איזה קובץ מתי

| קובץ | מתי |
|---|---|
| `setup.md` | **התחל כאן.** רשימת הגדרה לפי הסדר, עם מסלולי `Settings` מדויקים וטבלת פתרון תקלות |
| `custom-instructions.md` | טקסט מוכן להדבקה שכופה תשובות בעברית. ארבעה בלוקים בגדלים שונים, עם ספירת תווים |
| `voice-mode-addendum.md` | אם התשובות המדוברות ארוכות מדי, מקריאות רשימות או נשמעות ככתובות | 
| `shortcuts/README.md` | בניית שלושת הקיצורים, שיוך Back Tap ו-Action Button |

**סדר עבודה מומלץ:** `setup.md` שלבים 1–5 ← בדוק שהתשובות חוזרות בעברית ← רק אז `shortcuts/README.md`.

## שלושת הקיצורים, בשורה

- **ערוך הודעה** — מהלוח, בשלושה סגנונות (רשמי / ידידותי / קצר יותר), חזרה ללוח + התראה.
- **שאל בעברית** — פותח את Voice Mode. לתאום שלו קוראים `Ask Hebrew` כי Siri האנגלי לא מזהה שם עברי.
- **ערוך הודעה — שיתוף** — אותה עריכה מתפריט השיתוף של כל אפליקציה. ב-WhatsApp השתמש בגרסת הלוח.

## מה לא נבדק

לא הרצתי שום דבר מזה על מכשיר, ואין לי גישה למכשיר. שום קביעה כאן אינה תוצאה של בדיקה בפועל.

מה שסביר שיהיה שונה אצלך, ומסומן **UNVERIFIED** במקום שבו הוא מופיע:

- קיומם של `Dictation Languages` ב-iOS ו-`Speech > Main Language` באפליקציית ChatGPT.
