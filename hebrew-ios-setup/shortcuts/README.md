# Shortcuts — מפרטי בנייה

שלושה קיצורים לבנייה ידנית באפליקציית Shortcuts. כל מפרט הוא רשימה ממוספרת של פעולות עם ערכי פרמטרים מדויקים, בסדר שבו הן מופיעות בקנבס.

**יעד:** iPhone 17 Pro, iOS 26.x, ממשק iOS באנגלית.

---

## איך לקרוא את המפרטים

- שמות פעולות מופיעים ב-`Monospace` באנגלית — זה בדיוק מה שמקלידים בשורת החיפוש של Shortcuts.
- `Parameter: value` הוא שדה בתוך הפעולה.
- `[VAR]` הוא הפניה למשתנה שנוצר בשלב קודם. בפועל מוסיפים אותו מסרגל המשתנים מעל המקלדת, לא מקלידים את הסוגריים.
- שלב שמסומן **UNVERIFIED** מבוסס על שם פעולה או התנהגות שלא יכולתי לאמת. אין לי גישה למכשיר ולא בדקתי אף אחד מהקיצורים האלה בפועל.

## דרישות מקדימות

1. אפליקציית ChatGPT מותקנת ומחוברת לחשבון.
2. `Settings > Apps > Shortcuts > Private Sharing` — לא נדרש לבנייה עצמית.
3. `Settings > Notifications > Shortcuts > Allow Notifications` פעיל, אחרת ההתראה בסוף לא תופיע.

# א. "ערוך הודעה"

לוקח טקסט מהלוח, שולח לעריכה, מחזיר את התוצאה ללוח ומודיע.

זרימת השימוש: מסמנים טקסט באפליקציה כלשהי ← `Copy` ← מפעילים את הקיצור ← בוחרים סגנון ← מקבלים התראה ← `Paste`.

## Build 1 — דרך פעולת אפליקציית ChatGPT

זה ה-build הראשי. בלי מפתח API, בלי עלות לשימוש.

1. `Get Clipboard`
   - אין פרמטרים.
2. `Set Variable`
   - `Variable Name: SRC`
   - `Input: [Clipboard]`
3. `If`
   - `Input: [SRC]`
   - `Condition: does not have any value`
4. בתוך ענף ה-`If`: `Show Alert`
   - `Title: ערוך הודעה`
   - `Message: הלוח ריק. העתק טקסט ונסה שוב.`
   - `Show Cancel Button: Off`
5. בתוך ענף ה-`If`, מיד אחרי `Show Alert`: `Stop This Shortcut`
6. `End If` — נוצר אוטומטית. השאר את ענף ה-`Otherwise` ריק, או מחק אותו.
7. `Choose from Menu`
   - `Prompt: איך לערוך?`
   - פריט 1: `רשמי`
   - פריט 2: `ידידותי`
   - פריט 3: `קצר יותר`
8. בתוך `Case: רשמי` — `Text`
   - התוכן: וריאנט A מהסעיף "שלושת הפרומפטים" למטה.
9. בתוך `Case: רשמי`, מיד אחרי ה-`Text`: `Set Variable`
   - `Variable Name: P`
   - `Input: [Text]`
10. חזור על 8–9 בתוך `Case: ידידותי` עם וריאנט B, ובתוך `Case: קצר יותר` עם וריאנט C. בשלושת המקרים שם המשתנה הוא `P` — זה מכוון.
11. אחרי `End Menu`: `Text`
    - התוכן, בדיוק בשלוש שורות:
      ```
      [P]

      [SRC]
      ```
12. `Set Variable`
    - `Variable Name: MSG`
    - `Input: [Text]`
13. `Ask ChatGPT`
    - `Message: [MSG]`
    - **UNVERIFIED:** שם הפעולה. חפש `ChatGPT` בשורת החיפוש של Shortcuts וקח את הפעולה שמקבלת טקסט ומחזירה טקסט. שמות אפשריים: `Ask ChatGPT`, `Send Message`, `Chat`. אם אין אף פעולה כזו — עבור ל-Build 2.
    - אם לפעולה יש פרמטר `Model`, בחר את המודל החזק שיש לך גישה אליו.
    - אם יש פרמטר בסגנון `Open in App` או `Show When Run` — כבה אותו. אחרת הקיצור ייקח אותך לאפליקציה במקום להחזיר טקסט.
14. `Set Variable`
    - `Variable Name: OUT`
    - `Input: [ChatGPT]` (הפלט של שלב 13)
15. `If`
    - `Input: [OUT]`
    - `Condition: has any value`
16. בתוך ה-`If`: `Copy to Clipboard`
    - `Input: [OUT]`
    - `Local Only: Off`
    - `Expire At: ריק`
17. בתוך ה-`If`: `Show Notification`
    - `Title: ערוך הודעה`
    - `Body: [OUT]`
    - `Play Sound: On`
18. ב-`Otherwise`: `Show Notification`
    - `Title: ערוך הודעה`
    - `Body: לא חזרה תשובה. הטקסט המקורי נשאר בלוח.`
    - `Play Sound: On`
19. `End If`

**שם הקיצור:** `ערוך הודעה` (⌄ בראש המסך ← `Rename`).
**אייקון:** בחר צבע וסמל כלשהם — הם מה שיופיע ב-Lock Screen וב-Control Center.

> הערה על שלב 13: אם הפעולה של ChatGPT פותחת את האפליקציה במקום להחזיר טקסט לקיצור, ה-build הזה לא שמיש לזרימת "העתק, ערוך, הדבק". זה המצב שבו Build 2 הוא הפתרון, לא עקיפה.

## Build 2 — דרך OpenAI API

דטרמיניסטי, לא נוגע באפליקציית ChatGPT, לא מצריך אישור ידני. עולה כסף לפי שימוש ומחייב מפתח API על המכשיר.

שלבים 1–12 זהים ל-Build 1. במקום שלבים 13–14:

13. `Text`
    - התוכן: מפתח ה-API שלך, שורה אחת, בלי רווחים.
14. `Set Variable`
    - `Variable Name: KEY`
    - `Input: [Text]`
15. `Get Contents of URL`
    - `URL: https://api.openai.com/v1/chat/completions`
    - `Method: POST`
    - `Headers:`
      - `Authorization` = `Bearer [KEY]` — המילה `Bearer`, רווח, ואז המשתנה.
      - `Content-Type` = `application/json`
    - `Request Body: JSON`
    - שדות ה-JSON, בבנייה מתוך ממשק הפעולה:
      - `model` — `Text` — `MODEL_ID`
      - `temperature` — `Number` — `0.3`
      - `messages` — `Array`
        - פריט 1 — `Dictionary`
          - `role` — `Text` — `system`
          - `content` — `Text` — `[P]`
        - פריט 2 — `Dictionary`
          - `role` — `Text` — `user`
          - `content` — `Text` — `[SRC]`
    - שים לב: אין צורך לברוח מתווים. כשבונים את הגוף דרך שדות ה-JSON של הפעולה, Shortcuts מקודד מרכאות וירידות שורה בעצמו. אל תרכיב את ה-JSON כטקסט חופשי — טקסט מהלוח ישבור אותו.
16. `Get Dictionary Value`
    - `Get: Value for`
    - `Key: choices`
    - `in: [Contents of URL]`
17. `Get Item from List`
    - `Get: First Item`
    - `from: [Dictionary Value]`
18. `Get Dictionary Value`
    - `Get: Value for`
    - `Key: message`
    - `in: [Item from List]`
19. `Get Dictionary Value`
    - `Get: Value for`
    - `Key: content`
    - `in: [Dictionary Value]`
20. `Set Variable`
    - `Variable Name: OUT`
    - `Input: [Dictionary Value]` (של שלב 19)

משלב 21 והלאה — שלבים 15–19 של Build 1 (ה-`If`, `Copy to Clipboard`, שתי ההתראות), עם `[OUT]` כפי שהוגדר כאן.

**שני דברים לפני שמריצים:**

- **`MODEL_ID`** — החלף במזהה מודל שלמפתח שלך יש גישה אליו. אל תעתיק מזהה מתוך מסמך; שלוף את הרשימה בפועל: `GET https://api.openai.com/v1/models` עם אותו `Authorization` header. **UNVERIFIED** — אין לי דרך לדעת אילו מודלים זמינים בחשבון שלך או מה נכון היום.
- **המפתח יושב בתוך הקיצור בטקסט גלוי.** כל מי שפותח את הקיצור במכשיר רואה אותו, והוא נכלל בקיצור אם תשתף אותו. צור מפתח ייעודי ל-Project נפרד עם תקרת הוצאה ב-`platform.openai.com`, ואל תשתף את הקיצור. **אל תשמור את המפתח בקובץ בריפו הזה.**

`temperature: 0.3` הוא בחירה: עריכה צריכה להיות צפויה ולא יצירתית. אם התוצאות נוקשות מדי, העלה ל-`0.6`.

## שלושת הפרומפטים

הדבק כל אחד לתוך פעולת ה-`Text` המתאימה בשלב 8. הסיומת "החזר רק את ההודעה" קריטית — בלעדיה חוזרות הקדמות שנכנסות ללוח.


**וריאנט B — ידידותי**

```text

```

**וריאנט C — קצר יותר**

```text
קצר את ההודעה שמופיעה אחרי השורה הריקה לכל היותר לשני שלישים מאורכה, בעברית טבעית. שמור על כל העובדות, המספרים, התאריכים והשמות. אל תשמיט בקשה או שאלה שהופיעו במקור. אל תוסיף מידע. אל תשנה את רמת הרשמיות של המקור. החזר רק את ההודעה המקוצרת, בלי הקדמה, בלי הסבר, בלי מרכאות עוטפות ובלי חלופות.
```

# ב. "שאל בעברית"

פותח את Voice Mode של ChatGPT, שתומך בעברית מלאה בשני הכיוונים.

## קרא את זה לפני שאתה בונה

Siri לא תומך בעברית. לכן **שם עברי לא ניתן להפעלה קולית** — Siri האנגלי לא יזהה את "שאל בעברית" כשם קיצור. הפעלה קולית מחייבת שם באנגלית.

הפתרון: שני קיצורים זהים בתוכן, נבדלים בשם.

| קיצור | שם | מיועד ל |
|---|---|---|
| הראשי | `שאל בעברית` | Action Button, Home Screen, Control Center, Lock Screen |
| התאום | `Ask Hebrew` | הפעלה קולית: "Hey Siri, Ask Hebrew" |

זה לא פשרה על השפה. Siri רק צריך לזהות את שם הקיצור; מרגע שאפליקציית ChatGPT נפתחה, כל השיחה מתנהלת בעברית.

## הבנייה

1. `Open App`
   - `App: ChatGPT`
2. **החלף את שלב 1** בפעולת Voice של ChatGPT אם קיימת אצלך.
   - חפש `ChatGPT` בשורת החיפוש של Shortcuts.
   - **UNVERIFIED:** שם הפעולה. מועמדים: `Start Voice Conversation`, `Voice Mode`, `Start Voice Chat`.
   - אם קיימת — היא לבדה מספיקה, בלי `Open App` לפניה.

**מסלול חלופי אם אין פעולת Voice:** `Open URL` עם `chatgpt://voice`. **UNVERIFIED** — לא ידוע לי אם ה-URL scheme הזה נתמך. בדיקה: אם הקיצור נוחת במסך הצ'אט הרגיל ולא במצב הדיבור, ה-scheme לא נתמך; חזור ל-`Open App`.

**המסלול הכי אמין הוא בכלל לא קיצור:** אם אפליקציית ChatGPT מספקת Control של Voice, שייך אותו ישירות ל-Action Button (ראה למטה). זה חוסך את הקפיצה דרך Shortcuts. **UNVERIFIED** — לא ידוע לי אם ה-Control הזה קיים.

**שכפול לתאום:** בגלריית Shortcuts, לחיצה ארוכה על הקיצור ← `Duplicate` ← `Rename` ל-`Ask Hebrew`.

# ג. גרסת Share Sheet של (א)

אותה עריכה, אבל מטקסט שמסומן ומשותף מכל אפליקציה, בלי לעבור דרך הלוח.

## הבנייה

1. צור קיצור חדש בשם `ערוך הודעה — שיתוף`.
2. פתח `ⓘ` (Shortcut Details) בראש העורך:
   - `Show in Share Sheet: On`
   - `Share Sheet Types:` השאר מסומן **`Text`** בלבד. בטל `Images`, `Files`, `URLs`, `Media` והשאר. בלי זה הקיצור יופיע בכל תפריט שיתוף, כולל תמונות, ויקבל קלט שלא יידע לטפל בו.
   - `Show on Apple Watch: Off`
3. `Receive Text input from Share Sheet` — הפעולה הזו מופיעה אוטומטית בראש הקיצור אחרי שלב 2. אם היא מציעה `If there's no input:` בחר `Get Clipboard`. זה נותן נפילה חיננית לזרימת ההעתקה כשמפעילים את הקיצור לא דרך תפריט השיתוף.
4. `Set Variable`
   - `Variable Name: SRC`
   - `Input: [Shortcut Input]`
5. משלב 7 של Build 1 והלאה (ה-`Choose from Menu`), זהה לחלוטין — Build 1 או Build 2, לפי מה שבחרת.
6. במקום `Show Notification` בסוף, הוסף גם:
   - `Quick Look`
     - `Input: [OUT]`
   - זה מציג את הטקסט הערוך על המסך מיד, לפני שחוזרים לאפליקציה. הפעולה `Copy to Clipboard` נשארת — Share Sheet לא יכול להחליף את הטקסט באפליקציית המקור.

## מגבלה שכדאי לדעת עליה מראש

**תפריט השיתוף לא מחליף טקסט באפליקציה שממנה שיתפת.** הפלט תמיד עובר דרך הלוח, ואתה מדביק ידנית. החלפה במקום היא יכולת של Apple Writing Tools בלבד — וזו לא אופציה כאן: אין תמיכה בעברית ב-Apple Intelligence, ובנוסף Meta חוסמת את Writing Tools בתוך WhatsApp.

**ב-WhatsApp ספציפית** — סימון טקסט בתיבת ההקלדה נותן `Copy`, לא תמיד `Share`. לכן ב-WhatsApp השתמש בזרימת ההעתקה: `Copy` ← Back Tap ← `Paste`. גרסת ה-Share Sheet מיועדת ל-Mail, Notes, Safari, Slack ודומיהם.

# שיוך טריגרים

## Back Tap

1. `Settings > Accessibility > Touch > Back Tap`
2. `Double Tap`
3. גלול עד הסעיף `Shortcuts` בתחתית הרשימה — הקיצורים מופיעים מתחת לכל פעולות המערכת.
4. בחר `ערוך הודעה`.
5. אופציונלי: `Back Tap > Triple Tap` ← `שאל בעברית`.

הערות: Back Tap עובד גם כשהמסך נעול, אבל הקיצור עצמו יבקש ביטול נעילה לפני שירוץ. כיסוי עבה או מגן עבה מדי יכולים לפגוע בזיהוי — **UNVERIFIED** לגבי הכיסוי הספציפי שלך.

## Action Button — iPhone 17 Pro

**מסלול Shortcut:**
1. `Settings > Action Button`
2. החלק בקרוסלה עד `Shortcut`.
3. `Choose a Shortcut`
4. בחר `שאל בעברית`.

**מסלול Control** — עדיף אם ChatGPT מספקת Control של Voice:
1. `Settings > Action Button`
2. החלק עד `Controls`.
3. `Choose a Control` ← חפש `ChatGPT` ← בחר את ה-Control של Voice.
4. **UNVERIFIED** — אם ChatGPT לא מופיעה ברשימת ה-Controls, השתמש במסלול ה-Shortcut.

**Camera Control** (הכפתור בצד ימין ב-17 Pro) לא ניתן לשיוך לקיצורים. הוא מוגבל לפעולות מצלמה ו-Visual Intelligence. אל תבזבז עליו זמן.

## Control Center

1. החלק מטה מהפינה הימנית העליונה.
2. לחיצה ארוכה על אזור ריק ← `+` בפינה השמאלית העליונה ← `Add a Control`.
3. חפש `Shortcuts` ← בחר את ה-Control ← הקש עליו ← בחר `ערוך הודעה`.

## Lock Screen widget

1. לחיצה ארוכה על מסך הנעילה ← `Customize` ← `Lock Screen`.
2. הקש על אזור הווידג'טים מתחת לשעון.
3. `Shortcuts` ← בחר את הווידג'ט ← הקש עליו ← בחר `ערוך הודעה`.

## הפעלה קולית של הקיצור

"Hey Siri, Ask Hebrew" — בשם האנגלי בלבד, מהסיבה שהוסברה בסעיף ב'.
אין דרך להפעיל קיצור בקול בעברית. Siri לא מקבל עברית כשפת קלט בשום הגדרה.

# מה לא אומת כאן

אין לי גישה למכשיר. שום שלב בקובץ הזה לא הורץ ולא נבדק. הפריטים הבאים הם ניחוש מושכל שצריך אימות מולך:

- שם ופרמטרים של פעולת ה-ChatGPT בשלב 13 של Build 1, וכן אם היא מחזירה טקסט לקיצור או פותחת את האפליקציה.
- קיומה ושמה של פעולת Voice Mode בסעיף ב'.
- תמיכה ב-URL scheme בסגנון `chatgpt://voice`.
